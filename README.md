# Portfólio acadêmico — Douglas Melere

Projeto desenvolvido para a unidade curricular de Desenvolvimento Web da UNINTER, utilizando HTML, CSS e JavaScript, sem framework.

**[Ver demonstração](https://douglasmelere.github.io/portfolio-uninter/)**

Este repositório preserva o projeto acadêmico. O novo portfólio profissional de Douglas está em construção e será publicado separadamente.

## Páginas

- Início e apresentação.
- Sobre mim.
- Formação e cursos.
- Projetos com filtros por categoria.
- Contato com preparação de mensagem por e-mail.

## Executar localmente

Com Python 3 instalado, execute na raiz do projeto:

```sh
python3 -m http.server 8000
```

Abra <http://localhost:8000>. Não há dependências de instalação ou etapa de compilação.

## Contato e limitações

O formulário prepara uma mensagem no aplicativo de e-mail do visitante. O envio precisa ser confirmado nesse aplicativo; o site não possui servidor de e-mail e não anuncia uma entrega que não ocorreu.

Parte das imagens e fontes depende de serviços externos. Dados de formação, cursos e idiomas refletem o conteúdo acadêmico original e precisam de confirmação antes de serem reutilizados em um currículo atualizado.

## Publicação

O GitHub Pages publica a raiz da branch `main`. Não há domínio personalizado configurado neste repositório.
